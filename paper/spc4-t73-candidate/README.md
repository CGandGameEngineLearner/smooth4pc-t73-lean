# Trace-73 Cappell--Shaneson paper

This directory contains an English `amsart` preprint for a
skein-lasagna obstruction for a trace-73 Cappell--Shaneson sphere.  Exact
Artin--Magnus expansion and the pure-braid Andreadakis equality verify a
cubic-order statement for the public braid.  Geometric lemmas P0a--c, C1--C2,
and S remain Open.  No historical-PD identity is claimed.

## Build

From this directory in WSL:

```text
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
mkdir -p ../../output/pdf
cp main.pdf ../../output/pdf/spc4-t73-candidate.pdf
```

The repository build places the reviewed PDF at
`output/pdf/spc4-t73-candidate.pdf`.  Replace the provisional author block and
add submission metadata before an arXiv upload.

The extended P0 audit also requires GAP.  The tested host uses GAP 4.12.1,
installed on Ubuntu with `sudo apt-get install gap-core`.  GAP is used to test
whether the proposed spine images form a free basis of `F_3`.

rectangles, BPW/BHPW functoriality, and the statewise divided beta/psi cocone.
The paper constructs the actual endpoint factorization before applying the

The following retired Nielsen branch produced a valid partial audit: its
torus, matrix factorization, paired combinatorial Heegaard movie, 52
unit-slide templates, 62 sequential support placements,
handle-foot routes and radius-$1/32$ route thickenings pass.  The resulting
tubes avoid the section protection tube.  This branch remained open because
the cells were not composed into one simplex-by-simplex homeomorphism.  It is
not a P0 proof.

The passage comparison gives a stronger obstruction to this particular
route: the explicit Nielsen representative has reduced $m_2$ length 309 and
42 total detector channels, whereas the compact representative has length 311
and 44 channels.  The current Nielsen route is therefore falsified as the
source of the public collar.  This is a retired route; the Johnson alpha-side
construction below supplies the finite P0d word match, not an embedded collar.

The word-level comparison movie is generated by
`construct_t73_word_kirby_movie.py`: it uses 11,257 `r_yz` commutations and
one free bigon.  `generate_t73_ryz_band_schedule.py` binds every step to an
oriented local PL band template.  The unresolved input is the embedding of
those bands in the actual reduced link and the global product framing.

The `x^-1` IA correction restores 44 based word passages and passes GAP's
free-basis test, but `audit_t73_inner_conjugation_geometry.py` shows that it is
simultaneous inner conjugation: the unbased cyclic spine classes do not
change.  It therefore does not supply an embedded 44-channel collar.

`search_t73_dual_meridian_ia.py` tests non-inner IA corrections against a
strict complementary-handlebody condition.  The complete depth-three search
finds 751 detector-changing 44-channel candidates and no signed-permutation
dual-meridian extension.  This is a bounded sufficient-condition search, not
a global nonexistence proof.

finite fact.  The committed P0 certificate is Open: there is no certified

# QSTAR R7 legality criteria — pre-search freeze

transport, never from whether a convention makes `delta_3` vanish.

## 1. Fixed object

A convention is tested against one fixed datum:

1. the same framed handle presentation and the same actual `W1` filling;
2. the same oriented, based, owner-labelled cut tangle and boundary pairing;
3. the same collar endpoints, meridian/longitude convention, normal field,
   framing and dot/insertion position;
4. the same geometric point-push or movie, not merely the same unbased link,
   free-group reduction, closure or homology class.

Changing any item produces a different input, not an alternative legal
serialization of the fixed input.

## 2. Legal serialization

A serialization of the fixed movie is legal exactly when all of the following
hold.

1. It is a linear extension of the movie's geometric partial order.
2. Two adjacent events may be exchanged only when their supports are disjoint
   and the relevant strict interchange/movie-move theorem applies.
3. Braid relations may replace a word only after exact equality in the based,
   labelled braid/tangle category is proved.  Equality of closures, free words,
   permutations or homology classes is insufficient.
4. A cyclic rotation is allowed only when the basepoint crossing and detector
   insertion are transported through the same trace/cyclicity square.
5. Every coordinate change is simultaneous.  If `P` changes endpoint
   coordinates, then the operator, vector, shadow and row transform together:
   `W' = P W P^-1`, `u' = P u`, `Theta' = P Theta`, and
   `ell' = ell P^-1` (with the corresponding source/target versions).
   Reordering the word while keeping any of these fixed is illegal.
6. The serialized composite must be the strict functorial image of the fixed
   movie.  A list evaluator that is not proved to implement that composition
   convention does not establish legality.

These clauses do not mention the value or first nonzero order of `delta`.

## 3. Legal collar

A collar convention is legal for the fixed input exactly when:

1. it is an actual framed tubular collar of the registered embedded component;
2. it is isotopic to the registered collar relative to boundary, basepoints,
   owner labels, old input balls and detector insertion point;
3. the isotopy preserves the registered normal framing, rather than adding a
   Dehn/framing twist;
4. it carries the same `W1` filling preimage.  This requires an explicit
   source/target binding or a theorem proving the equality, not a matching word;
5. its induced map, endpoint standardization and detector row occur in one
   naturality square.  A nontrivial pure braid is retained in the transport;
   it is neither erased nor inserted on only one side;
6. any difference between two collars is generated by the certified relative
   isotopy/movie moves above.  A nontrivial element of the relative mapping
   class group defines a different collar and is not an alternative convention.

Again, zero or nonzero `delta_3` is not a legality clause.

## 4. Well-definedness test

For two conventions satisfying Sections 1–3, the simultaneous transport laws
must prove equality of the full scalar series

`delta_h(x) = ell_h (rho_h(W)-I) Phi_h Sh_h(x)`.

Consequently every coefficient and the first anomalous order must agree.  If
two structurally legal conventions give different series, `delta_h`—and hence
the statement `delta_3 != 0`—is not well-defined on the claimed geometric
object.  One may not repair this by declaring the preferred numerical output
to be canonical after seeing it.

Membership of the fixed geometric operator in `Gamma_3` is checked
independently of the expansion.  If a legal implementation of that same
operator has a degree-two term, either the `Gamma_3` binding or the claimed
representation/filtration theorem is false; the implementation is not rejected
merely because the result is inconvenient.

## 5. Precommitted consequences

1. If at least one L3 standard-member collar satisfies Sections 1–3 and its
   nonzero value survives the same downstream hypotheses, the proposed
   detector chain is dead.  The failing step is promotion of the
   presentation/movie coefficient to a smooth-manifold invariant; the standard
   and t73 members then behave alike at the bearing detector gate.
2. If none of the enumerated L3 collars is legal, the search is not a proof
   that no legal standard collar exists.  It only removes those 22 objects.
3. A general nonexistence theorem under Sections 1–3 would upgrade the
   detector to a relative-presentation invariant on the precisely stated class
   of standard members covered by that theorem—not automatically all standard
   homotopy four-spheres.
4. For L2, if exactly one ordering satisfies Section 2, only that ordering's
   series and first anomaly count.  If both satisfy it, their values must agree
   or well-definedness fails.  If neither satisfies it, neither number bears on
   the geometric chain.

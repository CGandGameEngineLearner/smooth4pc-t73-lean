## Cubic transport theorem

`Smooth4PC/CubicJet.lean` defines the coefficients through order three of a
rational-linear map.  It proves, on the full source, that if an anomaly starts
in order three and a source or target transport has identity constant term,
then the cubic coefficient is unchanged.  In formulas,

\[
K(h)=h^3K_3+O(h^4),\qquad Q(h)=I+O(h)
\]

implies

\[
[h^3](KQ)=K_3,\qquad [h^3](QK)=K_3.
\]

The file was checked with Lean 4.32.1 using:

```text
lake env lean Smooth4PC/CubicJet.lean
```

This discharges the algebra behind the repeated claim that positive or pure
transport corrections affect the detector only from order four onward.  It
does not assert that an actual geometric transport has identity constant
term.
